# 🤖 KAACRASH BAILEYS

Library WhatsApp Web berbasis **Baileys** yang dikustomisasi khusus untuk keperluan bot dan script bug. Fork ini mendukung `require` (CommonJS) dan `import` (ESM).

## 👤 Creator
- **kaacrash** (ripazka5-cmd)

## ✨ Fitur
- ✅ Support all type message
- ✅ Support `require` & `import`
- ✅ Notifikasi pesan selalu muncul (Addsender)
- ✅ Banner custom KAACRASH
- ✅ Auto-follow channel (opsional)

## 🚀 Cara Install
Tambahkan ke `package.json` script bot kamu:
```json
"dependencies": {
  "@kaacrash/baileys": "github:ripazka5-cmd/Baileys",
  "jimp": "^1.6.1"
}
